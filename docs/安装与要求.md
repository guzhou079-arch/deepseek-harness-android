# 安装与系统要求

## 一、需要什么

| 项 | 要求 |
|---|---|
| **Android 版本** | **7.0（API 24）及以上**。⚠️ 无障碍**截图**、虚拟屏等高级能力需要 **Android 11+**，低版本装了也能聊天，但部分自动化能力不可用 |
| **存储空间** | 安装包约 **95MB**；安装后应用数据约 **0.6GB**（运行时 + 引擎 + 会话）；另可选下载构建环境约 **340MB** |
| **网络** | 需要联网（AI 模型在远端）。局域网访问默认关闭 |
| **硬件** | 不需要 root；NFC 读卡需要手机有 NFC |
| **权限** | 核心聊天只需要网络；其余权限按需授予，详见 [权限与隐私](权限与隐私.md) |

## 二、下载与校验

只从**本仓库的 Releases** 下载。

每个 Release 的说明里带该 APK 的 **SHA-256** 和**签名证书指纹**，装前可以核对：

```sh
sha256sum DeepSeekHarness-v1.30.apk     # 与 Release 说明里的值比对
```

## 三、安装

1. 点开下载好的 APK；系统会引导你允许「安装未知应用」。
2. 安装完成后打开 App。
3. **首次启动会解压运行时**（几百 MB，视机型约 1–3 分钟，界面上有进度）。
4. 按提示登录（手机号 / 账号）。
5. 可选：控制台里按需开启悬浮球、无障碍等能力。

## 四、更新（**先读这一节**）

- **只从本仓库 Releases 更新**，直接覆盖安装即可。
- ⛔ **不要卸载重装** —— 卸载会清空应用私有数据（会话历史、运行环境、配置）。
- 若报 `INSTALL_FAILED_UPDATE_INCOMPATIBLE`：说明你现在装的是**别的签名**的同名包。
  这时**先别卸载**：先在 App 内「控制台 → 救援 → 导出全部数据」备份，再决定怎么处理。
- 升级前建议每次都导出一次数据（同上路径）。

## 五、卸载 / 换机 / 迁移

- **导出**：控制台 →「救援」→「导出全部数据」→ 得到一个 zip（含会话、配置、工作区）。
- **导入**：换机或重装后 →「从备份导入还原」→ 选那个 zip。
- ⚠️ 备份 zip 里**含登录凭据**，请像对待密码一样保管，别随手转发。
- 卸载会删掉应用私有数据；`/sdcard/DeepSeekHarness` 下的导出包、截图、构建环境分卷**不会**被卸载删除。

## 六、装不上怎么办

| 症状 | 原因 / 处理 |
|---|---|
| `INSTALL_FAILED_UPDATE_INCOMPATIBLE` | 签名不同的同名包。先备份，再决定是否卸载重装（见第四节） |
| `INSTALL_FAILED_VERSION_DOWNGRADE` | 你装的版本比现有版本低。用更新的版本，或先备份再卸载 |
| 解析包错误 | 下载不完整 —— 重新下载并核对 SHA-256 |
| 首次启动一直转圈 | 正在解压运行时，等几分钟；反复失败可在控制台里重试解压 |
| 启动后引擎起不来 | 控制台有「安全模式」与「修复」入口；仍不行请带上日志提 Issue |
