# 常见问题（FAQ）

> 想反馈问题：请到本仓库开 Issue，并附上**版本号、机型、Android 版本、复现步骤、日志**。
> ⛔ 不要把 API Key、登录凭据、完整会话内容或含个人信息的截图贴到 Issue 里。

## 安装与升级

**Q：报 `INSTALL_FAILED_UPDATE_INCOMPATIBLE` 怎么办？**
A：说明你手机上已经有一个**签名不同**的同名 App（官方原版、别人的包、或自己出的包）。
**先别卸载** —— 先在 App 内「控制台 → 救援 → 导出全部数据」备份，再决定是否卸载重装。
这个报错本身是在提醒你"来源不对"，不是故障。

**Q：报版本降级（`INSTALL_FAILED_VERSION_DOWNGRADE`）？**
A：你要装的版本比现有的低。装更新的版本；确实要降级就先备份、再卸载重装。

**Q：升级后数据会丢吗？**
A：从本仓库 Releases **覆盖安装**不会丢数据。卸载重装会丢（会话、配置、运行环境）。

## 启动与运行

**Q：首次启动一直转圈？**
A：它在解压运行时（几百 MB），视机型 1–3 分钟。反复失败可以在控制台里重试解压；
建议先确认存储空间够（应用数据约 0.6GB，另需构建环境 340MB 可选）。

**Q：引擎起不来 / 卡在启动界面？**
A：控制台有「安全模式」（旁置坏掉的配置、不动你的数据）与「修复 / 重新解压」入口。
如果之前装过插件导致配置写坏，安全模式通常能救回来。

**Q：登录时跳浏览器，回不来 App？**
A：登录完成后应该会自动跳回。没跳回就手动切回 App；仍不行请带上机型与系统版本反馈。

## 悬浮球 / 桌宠

**Q：找不到悬浮球？**
A：两种正常情况：① 你在**用这个 App 本身**（App 在前台时悬浮球自动隐藏，切到桌面就能看到）；
② 你之前点过「隐藏」，它在屏幕边缘只露出一半。也可以在通知栏点「开关面板」把它叫出来。

**Q：点了球没反应 / 要按住最底部才行？**
A：这是早期版本的已知问题，已在 **v1.30** 修好。请升级到最新版。

**Q：重启手机 / 重启 App 后球不见了？**
A：从 **v1.30** 起会记住你的开/关意图：开过的人重启后自动恢复；从没开过的人不会被打扰。

## 权限相关

**Q：无障碍服务自己关了？**
A：部分系统（尤其厂商 ROM）会在装应用、清后台后自动关闭无障碍服务。
去「系统设置 → 无障碍 → 已下载的服务 → DeepSeek Harness 屏幕助手」重新打开即可。
不开也不影响聊天，只是自动化能力不可用。

**Q：读不到通知 / 验证码？**
A：依次确认：① 通知权限已给；② 无障碍服务在运行；③ 该类通知没有被系统的"通知折叠/摘要"吞掉。

**Q：截屏 / 虚拟屏用不了？**
A：无障碍**截图**需要 **Android 11+**；**虚拟屏**还需要额外的特权通道（Shizuku）。
版本或权限不够时，这两项不可用，其余功能不受影响。

**Q：定时任务不准？**
A：给「精确闹钟」权限；再把 App 加入系统的「不允许后台限制 / 电池优化白名单」。

## 构建环境（想自己出包的人）

**Q：构建环境下载失败 / 很慢？**
A：建议在 Wi-Fi 下下载（约 193MB，解压后约 340MB）；分卷会留在
`/sdcard/DeepSeekHarness/buildenv`，**重装 App 只需重新解压、不用重新下载**；
已下载且校验通过的卷会自动跳过。

**Q：自建的包能覆盖官方包吗？**
A：**不能**。自建包用你自己的钥匙签名，与官方包签名不同；两者只能卸载重装其一。
只想用 AI 的人请装官方 Releases；要自建请先读 [自建环境与出包](自建环境与出包.md)。

## 其它

**Q：占多大空间？**
A：APK 约 95MB；应用数据约 0.6GB；构建环境（可选）约 340MB。

**Q：支持平板 / 横屏吗？**
A：手机竖屏为主要目标；横屏与平板可用但未专门适配，遇到布局问题欢迎反馈。

**Q：会不会偷偷上传我的数据？**
A：本项目不运营服务器、无统计与埋点；只有你发给 AI 的内容会送到你自己配置的模型服务。
详见 [权限与隐私](权限与隐私.md)。
