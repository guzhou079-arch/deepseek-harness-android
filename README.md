# DeepSeek Harness 安卓版 · 发布仓库

这个仓库只用来存放安装包（Releases），**不含源码**。

## 下载

到 [Releases](../../releases) 页面，下载最新的 `DeepSeekHarness-vX.YZ.apk`。

## 安装

1. 下载 APK
2. 点击安装（首次需要在系统里允许「安装未知来源应用」）
3. 如果已经装过同签名的旧版本，会**原地覆盖升级，数据不丢失**

## 应用内更新

App 启动时会自动检查本仓库的最新 Release，有新版本会弹提示，点「去下载」即可。

> 若提示网络失败或页面打不开，通常是网络环境问题。
