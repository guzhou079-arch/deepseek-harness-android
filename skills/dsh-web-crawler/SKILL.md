# 网页与后台数据自动化抓取技能 (browser-skill)

一句话：**告别手动复制粘贴，把复杂的网页与后台表格一键转为整洁的 Markdown / JSON**。

## 🎯 两种抓取通道（按优先级选择）

1. **公开网页通道（免特权、零开销、极速）**：
   - 使用 `web_fetch` 工具直连拉取页面 HTML 并解码；
   - 配合内置脚本进行 DOM 清洗，去除导航栏、广告和冗余样式，只提取纯净正文与表格。

2. **带登录态/动态渲染通道（手机端无障碍原生桥）**：
   - 目标需要登录（如个人后台、订单列表、管理控制台）：
   - 引导用户在手机浏览器中打开对应页面；
   - 通过 `android_screen` / 无障碍桥 (`http://127.0.0.1:3181/dump`) 结构化读取页面文本与表格节点；
   - 自动聚合分页内容，拼装为完整的报表交付。

## 🛠️ 数据结构化提取原则

- **长列表转 Markdown 表格**：自动识别标题行与数据列，生成标准 GFM 表格；
- **文章/文档转清晰段落**：保留关键标题分级 (`#`, `##`)、引用块与要点列表；
- **严禁乱抓无关噪声**：自动剔除 Cookie 声明、页脚版权、无关侧边栏链接。
