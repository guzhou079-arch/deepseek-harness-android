# 淘宝闪购点单（虚拟屏版）

一句话需求 → 一屏真实店铺/商品 → 推荐卡片 → 用户选 → 选规格 → 提交订单（不付款）。

## 0. 硬约束（先读，别越界）

- **只在虚拟屏操作**（display 由 `vs.sh disp` 现测，通常 7）。**主屏一律不碰**：不 am start、不 force-stop 主屏 App、不 input 到 display 0。
- **收工顺序固定**：`am force-stop com.taobao.taobao` → `vscreen_close`。
  反了会把淘宝任务弹回主屏（用户正在放视频/聊天时尤其糟）。
- 虚拟屏**没有控件树**（`vs.sh dump` 读到的是主屏，别信）。淘宝页只能**看截图 + 按坐标点**。
- 截图很贵：一律 `vs.sh see`（自动缩到 1/2）。要看清小字才用原图。
- 人民币带「凑单价/新人价」的 ¥0.01 是优惠占位，**不是真实单价**，报给用户时必须折算说明。

## 1. 工具

```sh
VS=/sdcard/DeepSeekHarness/tools/vs.sh
sh $VS disp                 # displayId
sh $VS launch com.taobao.taobao   # 启动到虚拟屏（走桥，不是 am start）
sh $VS see /sdcard/DeepSeekHarness/vscreen/q.png   # 抓帧，1/2 缩放
sh $VS tap X Y              # 坐标按原图 1008x1792 算
sh $VS swipe X1 Y1 X2 Y2 [ms]
sh $VS key back
```

看图上量到的像素 → 原图坐标 ×2（因为 see 缩了一半）；直接按「原图比例」换算最稳：
`X = 预览宽/1008 × 目标x`。

## 2. 实测路径（2026-10-18，display 7，1008x1792）

冷启动淘宝约 12 秒，会弹双 11 弹窗（点「领」或右上角 X 关掉，back 不管用）。

```
启动淘宝 → 首页
tap (897,451)        淘宝闪购图标（第二排最右，红色「极速版」旁边）
tap (262,829)        「奶茶咖啡」分类 tab —— 绕过中文搜索的关键
→ 奶茶店铺列表（每个卡片自带店名/评分/月售/起送/配送费/时间/距离/招牌商品价）
tap (420,1406)       第一家店铺卡片（点店名区，别点「去使用」红包按钮）
→ 店铺页（外送/自取、起送价、菜单）
```

**为什么不用搜索框**：淘宝搜索框只吃 ASCII 键盘输入，中文 `input text` 静默丢弃、
`keyevent 279`(PASTE)/Ctrl+A 也不生效（见 lesson-taobao-search-filters-and-vscreen-input）。
分类 tab 是绕开中文输入的稳定入口。

其他分类 tab（同一行）：汉堡披萨、便当简餐、超市便利、粥食。

## 3. 读卡片 → 推荐

列表页一屏通常 2~3 家店。判据：能看到「评分 x.x 分」+「起送 ¥xx」+「xx 分钟 xx km」。

排序权重（用户没特别说时）：
1. 配送时间（≤25 分钟优先）
2. 免配送费 / 起送价低
3. 评分（4.6 以上）
4. 意图匹配（用户说「便宜」→ 优先蜜雪/低起送；说「好喝点」→ 优先高评分品牌）

多屏时：`vs.sh swipe 500 1600 500 700 400` 再 `see`，最多翻 2 屏就够给方案。

## 4. 输出格式（照这个给用户）

```
附近能送到的几家：

1. 蜜雪冰城(星城店) 4.6分 · 21分钟 · 2.3km · 起送¥18 免配送
   招牌：桃果清爽 ¥18 / 三拼霸霸奶茶 ¥0.01 凑单价
2. 沪上阿姨(房山燕隆汇店) 4.8分 · 24分钟 · 2.5km · 起送¥18 免配送
   招牌：抹茶波波 ¥1 凑单（原¥6）/ 黄金芒芒酸奶 ¥2 凑单（原¥7）

选哪家？定了我就点进去选项、调糖度，走到提交订单给你付款。
```

不要罗列全部商品；每家给 2 个代表款即可。

## 5. 继续下单（用户选定后）

1. 点进店铺 → 菜单区（要往下滑，banner 占半屏）
2. 点目标商品 → 规格弹层（冷/热、糖度、加料）
3. 规格按钮点完 → 「选好了/加入购物车」
4. 到「提交订单」页**停下**，把金额和地址念给用户，等他本人付款
5. 绝不替用户输密码/指纹；不点「立即支付」

## 6. 已知坑

- 点商品大图会进全屏图集，再 back 一次才回宝贝页。
- 关虚拟屏前必须 force-stop，否则淘宝会跳到主屏。
- 淘宝首页顶部 tab 有「闪购」和首页图标区「淘宝闪购」，两个都能进，图标区更快。
- 虚拟屏偶发卡顿：截图 hash 连续两次相同且画面明显没变 → 等 3 秒再截，别连点。
